## 3. 必须人工主导的卡

以下 8 张卡不接受 AI 自行决断，AI 只能在其给定结论下实现：

| 卡 | 人工职责 | 原因 |

| T-01 | 契约取舍、H 编号分配 | 契约一旦冻结，改动成本最高 |
| T-04 | 密级口径与导出审批规则 | 涉密判断不能由模型推断 |

| T-07 | SLA 时限与等级取值 | 属业主管理口径 |
| T-13 | 升级阈值与通知渠道 | 涉及责任划分 |

| T-23 | 验收口径与样本量 | 决定能否签字验收 |

其余 16 张卡可由 AI 会话独立完成，但 T-04、T-07、T-18、T-19 的实现细节仍需人工复核一次。
