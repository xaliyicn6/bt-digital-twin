# T-15 Cesium 加载与点云拾取

| 项 | 内容 |
| --- | --- |
| 阶段 | P4 |
| 依赖前置 | T-14 |
| 产出 | 3D Tiles 加载、点预算控制、拾取反查到构件、离线底图、视角书签 |
| 验收门 | 首屏 ≤3 s（P-01 条件下）；拾取准确率 ≥95%；断网可用 |
| 预估工作量 | 6 人日 / 4 卡 |
| 人工主导 | 否 |
| 外部阻塞 | 阻塞于 C-09（渲染机型与点预算） |

## 1. 目标

让用户在浏览器里看清点云、点到构件、拿到构件编码，且不依赖外网。

## 2. 输入

- API-07、API-08
- tileset.json
- component 编码

## 3. 改动范围

- 允许：frontend/src/cesium/**、views/viewer/**
- 禁止：引入 Cesium Ion 资源或在线底图

超出上述范围即视为越权改动，即使代码正确也退回。

## 4. 实现要点

- `Ion.defaultAccessToken = undefined`，所有影像/地形走本地服务
- 单帧点预算 150 万，超限先降点大小再降 SSE
- 拾取用 `scene.pick` 拿 tile 自定义属性，再反查 component_code；查不到返回空而非报错
- 实体与监听器在组件卸载时销毁，防泄漏

## 5. DoD（可验证的完成定义）

- P-01/P-02 条件卡片下实测达标（记录机型与网络）
- 点击墩身返回正确 component_code ≥95%
- 断网后场景与底图仍可用
- 连续切换 20 次结构无内存增长 > 10%

## 6. 验收用例

| # | 输入 | 操作 | 期望结果 |
| --- | --- | --- | --- |
| 1 | 点击点云中的矩形墩 | pick | 返回 B001-K03-PIR-P01-001 并高亮 |
| 2 | 在无属性瓦片上点击 | pick | 返回 null，界面提示“该处无构件信息”，不抛异常 |
| 3 | 断网后重新加载页面 | 刷新 | 本地底图与已缓存瓦片可见，无外网请求 |

## 7. 依赖与顺序

T-14 之后；T-23 精度测试会复用它做人工判读。

## 8. 常见坑

- 不要用屏幕坐标反算世界坐标做拾取
- 不要把 tileset 全量下载到内存
- 不要在 render loop 里做 DOM 操作
